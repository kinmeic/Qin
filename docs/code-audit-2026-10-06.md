# Qin 代码审计与修复记录

日期：2026-10-06。审计对象：当前工作区，包含尚未提交的 `qin tui` 和输入框下方状态展示功能。

审计完成后，按用户要求增加了 Shift+Tab 授权模式切换及显式 YOLO 模式。YOLO 对下一轮任务跳过所有工具审批，包括高风险审批，仍保留禁用工具和禁止操作规则；不更改配置文件。下文测试数量记录的是审计完成时的结果，不包含后续授权模式改动；后续改动已通过编译检查。

## 范围与方法

阅读 `src/` 全部模块，检查模型请求与响应解析、工具执行、审批、取消、文件操作、持久化、撤销、知识库、终端渲染、配置、更新、安装及打包脚本、GitHub Actions 和依赖锁文件。结合静态检查、回归测试、本地 HTTP 模拟服务、发布构建和离线回放验证修复。

P1 表示可能导致危险操作绕过确认、信息泄露、执行失控或状态丢失；P2 表示恢复、交互、资源限制或构建方面的重要缺陷；P3 表示较低风险的正确性问题。下表各项已在本轮修复。

## 发现与修复

| 级别 | 问题 | 修复与验证 |
| --- | --- | --- |
| P1 | Shell 的任务级 `All` 审批也会跳过高风险操作的再次确认 | 高风险操作独立审批，不提供 `All`；同时验证已有 `All`、`--yes`、`approval=never` 的组合。 |
| P1 | 引号或转义拆分命令名可能漏过高风险识别 | 使用已有 Shell 分词器识别程序名称、环境赋值和嵌套 Shell；增加相关分类测试。复杂 Shell 的识别仍属于保守检查，见下文边界。 |
| P1 | 直接删除工具没有与 Shell 一致地保护系统顶层目录 | 统一保护系统目录、其规范路径、用户主目录和当前工作目录；测试仅执行路径检查。 |
| P1 | Shell 关闭 stdout/stderr 后，等待进程退出的阶段失去超时和取消保护 | 将 `child.wait()` 纳入同一截止时间和取消监听；验证关闭输出后运行 `sleep` 的超时及取消。 |
| P1 | 脱敏对带空格、引号、JSON 键名和 Unicode 空白的值不完整；推进字节偏移还可能破坏 UTF-8 边界 | 重写敏感值范围识别，处理 Bearer、带引号和转义引号的值，始终使用合法字符边界；增加中文与 Unicode 测试。 |
| P1 | 模型和命令的流式输出按分片脱敏，分片边界可能泄露秘密 | 共用有状态的流式脱敏器；测试不同分片位置和逐字符输入。未结束的敏感值缓冲有大小上限。 |
| P1 | 模型流提前断开可能被当成完整回答或工具调用 | 要求 `[DONE]` 或有效的 `finish_reason`；拒绝错误事件、长度截断和无结束标记的响应；不执行其中的工具调用。 |
| P1 | 临时 JSON/Redis 会话先读取后加会话锁，两个进程可能互相覆盖旧状态 | 在读取和迁移前取得存储锁，保持至进程释放存储；Redis 锁身份包含地址、数据库和键，排除认证信息；测试锁的排他性、释放及凭据变化。 |
| P2 | TUI 退出时仍保留事件接收器，后台可能永远等待审批或终端交接确认 | 先释放事件接收器，再等待工作线程；审批和确认使用容量为 1 的回复通道；验证放弃等待后工作线程能退出。终端初始化也移至工作线程启动前。 |
| P2 | TUI 裁剪活动记录时没有同步修正正在流式写入的消息索引 | 统一插入和裁剪逻辑，修正索引并检查访问；验证持续输出期间添加活动消息。 |
| P2 | TUI 超长对话的滚动量超出 `u16` 后显示错误，显示数据也缺少总字节上限 | 对话先按显示宽度分行，再用 `usize` 选择可见行；增加单条和整体显示缓冲上限；验证超过 65,535 行的显示和小终端渲染。持久化消息不因此裁剪。 |
| P2 | 输入光标只计算硬换行，中文宽字符、软换行和末尾换行位置错误 | 按 grapheme 和显示宽度计算输入行与光标；测试中文、整行宽度和末尾空行。 |
| P2 | 复制到新文件时没有记录撤销；同路径复制或移动会产生无效撤销记录 | 登记新文件创建，拒绝同源同目标操作；验证复制后 `undo` 能移除新文件。 |
| P2 | 移入回收目录后才登记恢复位置，崩溃窗口内可能丢失撤销信息 | 将恢复位置登记移至实际移动之前。 |
| P2 | 撤销快照丢失原始文件权限，也没有验证已有 SHA-256 信息 | SQLite 增加第 5 版迁移保存普通权限位；恢复前验证快照校验和，拒绝异常路径、快照文件名和被替换的符号链接父目录；同步快照目录。验证执行位恢复、损坏快照和父目录替换。 |
| P2 | 普通读取在文件被替换为 FIFO 等特殊文件时可能阻塞 | Unix 打开文件时使用 `O_NOFOLLOW | O_NONBLOCK`，再检查实际文件句柄的类型；配置和会话文件同时复查私有权限。验证 FIFO 不会阻塞读取。 |
| P2 | 原子写入可能保留原文件的 setuid/setgid 权限位 | 普通写入和恢复只保留普通权限位；验证特殊权限位被移除。 |
| P2 | `apply_patch` 依赖读取前的长度检查，文件增长时可能超过限制；空匹配与过大的新内容也未拒绝 | 有界读取并复查长度，拒绝空 `old_text` 和超限结果；测试失败时原文件不变。 |
| P2 | 网络工具和自动记忆提取没有及时响应 TUI 取消 | 将等待纳入取消监听；网络工具取消后补齐当前及尚未执行的工具结果。验证取消网络请求后会话仍满足配对不变量，后续写入不会执行。 |
| P2 | UI 通道关闭可能阻止工具审计写入，取消通知失败还可能阻止补齐工具结果 | 优先持久化审计；中断通知采用尽力发送；验证关闭 TUI 通道后仍能完成中断记录。 |
| P2 | 更新程序仅验证初始下载地址；非目标归档条目缺少解压资源限制 | 每次重定向均检查 HTTPS 与 GitHub 域名；限制归档条目数、声明总大小和解压读取量；回滚采用安全打开和有界读取。验证下载地址与非目标超大条目。 |
| P2 | TUI 依赖包含有安全公告的旧 `lru`，以及未维护的 `paste` | 升级 Ratatui 至 0.30.2、Crossterm 至 0.29.0；锁文件中的 `lru` 为 0.18.5，移除 `paste`。最终依赖扫描无漏洞或告警。 |
| P2 | 项目声明 Rust 1.85，但代码已有 Rust 1.88 才稳定的语法，最低版本 CI 会失败 | 将 Cargo、README 和 CI 最低版本统一为 1.88；实际执行该版本的全部目标编译检查。修复 Clippy 告警。 |
| P2 | 打包名称和版本可包含路径分隔符或控制字段换行 | 限制为安全的名称/版本字符；验证危险输入返回错误且不写入输出目录。 |
| P3 | 输入历史超过 100 条后保留最旧记录、丢失最新记录 | 淘汰最旧输入；验证第 105 条提交后仍可取回最近输入。 |
| P3 | 所有以 `/` 开头的消息都被当成命令，绝对路径请求无法发送 | 仅识别已有的完整斜杠命令；验证绝对路径请求正常发送。 |
| P3 | 新提交的用户消息没有按历史消息相同规则脱敏；临时会话替换默认 Enter 表示同意 | 统一显示脱敏；Enter 默认保留现有临时会话。 |
| P3 | 超时错误因包含 “cancel” 被 TUI 显示为用户取消 | 分开描述运行时限与用户取消，按明确错误信息显示状态。 |
| P3 | 知识库递归遍历缺少目录数量上限；向量计算可能溢出；记忆提取端点可能重复拼接 | 改为迭代遍历并限制目录条目数；拒绝非有限向量，半精度溢出时保存 f32，余弦使用 f64；复用聊天端点构建。 |
| P3 | 撤销标识前缀将 SQL 通配符当成匹配模式；`Durable` 配置通过校验却未启用 FULL 同步 | 使用字面前缀匹配，统一大小写处理；增加对应测试。临时会话新建持久化失败时也恢复此前内存状态。 |

## 兼容性与边界

- 最低 Rust 版本提高至 1.88；数据库会自动迁移至第 5 版，新增权限字段。
- 原有快照没有保存原始权限时，无法补回已经丢失的权限信息。撤销保存内容和普通权限位，不重建所有者、ACL、扩展属性或硬链接关系。
- 临时会话存储在同一主机上采用排他锁；运行 TUI 时，对同一临时存储的另一进程会被拒绝。Redis 存储面向单个 Qin 主机，不提供跨主机分布式互斥。
- TUI 显示缓冲限制为单条 128 KiB、整体 2 MiB、最多 500 条；截断会显示提示，数据库消息保留原有持久化规则。
- Shell 检查与文件路径检查不构成操作系统沙箱；复杂脚本语义和并发父目录替换无法仅靠这些检查完全隔离。
- 本轮未在 Linux/OpenWrt 实机运行，也未调用真实模型/搜索服务或执行正式发布。真实终端中的输入法候选确认、Shift+Enter 编码和 sudo 交接仍依赖终端/操作系统行为，自动测试不能证明所有终端组合下都一致。
